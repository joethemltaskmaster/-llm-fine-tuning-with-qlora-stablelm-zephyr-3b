# results/runs/

TensorBoard event logs. The Hugging Face `Trainer` writes here automatically because `report_to="tensorboard"` is set in `FineTuneConfig`; the logging directory defaults to `<output_dir>/runs`.

Everything here is **generated by a training run** and is git-ignored. Only this README is tracked.

## Layout

Each training run creates its own subfolder named `<date-time>_<hostname>`:

```
results/runs/
└── Oct17_04-37-12_my-machine/
    └── events.out.tfevents.<timestamp>.<hostname>.<pid>.0
```

Metrics are logged every `logging_steps` steps (default `25`). Expect training loss, learning rate and gradient norm. Resuming from a checkpoint typically adds a new event file rather than overwriting the old one, so a resumed run shows up as a continuous curve.

## Viewing the logs

From the project root:

```bash
tensorboard --logdir results/runs
```

In Google Colab or Jupyter:

```python
%load_ext tensorboard
%tensorboard --logdir results/runs
```

## Notes

- To compare runs (for example `--lora_r 8` against `--lora_r 16`), keep their subfolders side by side here and point `--logdir` at `results/runs`.
- `tensorboard` is already listed in `requirements.txt`.
- Switching `report_to` to `"wandb"` in `config.py` sends metrics to Weights & Biases instead; this folder will then stay empty.
